# Analsis_Energetico_Argentina_2019_2024
# Balance Energético de Argentina (2019–2024)

Este proyecto analiza la evolución de la matriz energética argentina entre 2019 y 2024, utilizando datos oficiales del Ministerio de Economía.  
El objetivo es comprender cómo distintas fuentes —primarias, secundarias y renovables— han contribuido al balance nacional, expresadas en Tonelada Equivalente de Petróleo (TEP).

## Contenido
- **Energías Primarias**: petróleo, gas natural de pozo, hidráulica y nuclear.  
- **Energías Secundarias**: electricidad, gases, biodiesel y motonafta.  
- **Energías Renovables**: solar, eólica, aceites y alcoholes.  
- **Transformación**: análisis de cómo las fuentes primarias se convierten en secundarias para llegar al consumo final.  
- **Dashboards comparativos**: oferta vs consumo, evolución de renovables y participación de cada fuente.

## Fuente de datos
Los datos fueron extraídos del sitio oficial:  
[Balances Energéticos – Ministerio de Economía](https://www.argentina.gob.ar/economia/energia/planeamiento-energetico/balances-energeticos)

## Herramientas utilizadas
- **Python (pandas)**: limpieza y filtrado de datos, conversión del archivo Excel de formato ancho a formato largo para facilitar el análisis.  
- **Tableau Public**: visualización interactiva y construcción de dashboards narrativos.  
- **Excel**: almacenamiento inicial y verificación de la estructura de los datos.  
- Unidad de medida: Tonelada Equivalente de Petróleo (TEP).  

## Objetivo
Ofrecer una visión clara y narrativa de la matriz energética argentina, destacando el rol de las energías tradicionales y el crecimiento incipiente de las renovables en el proceso de transición energética.
